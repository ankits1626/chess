# Project Setup Details

This document provides a detailed breakdown of the project setup, including the technologies used and the role of each file and directory.

## 1. Technology Stack

The project is built using a modern frontend technology stack:

- **Package Manager:** `pnpm` is used for fast and efficient dependency management.
- **Build Tool:** **Vite** provides a rapid development server and optimized build process.
- **Framework:** **React** is the UI library for building components.
- **Language:** **TypeScript** adds static typing to JavaScript for improved code quality and maintainability.
- **Styling:** **Tailwind CSS** is used for utility-first CSS styling.

## 3. File-by-File Breakdown

### Root Directory (`frontend/app/`)

- **`package.json`**: This is the project's manifest file. It defines the project's name, version, scripts (like `dev`, `build`, `lint`), and lists all the dependencies (`react`, `chess.js`) and development dependencies (`vite`, `typescript`, `tailwindcss`).

- **`pnpm-lock.yaml`**: This file is automatically generated by `pnpm`. It locks down the exact versions of all dependencies and their sub-dependencies to ensure that every installation is identical, leading to a stable and reproducible build.

- **`vite.config.ts`**: The main configuration file for Vite. We have configured it to use the React and Tailwind CSS plugins, enabling a fast development server and an optimized build process.

- **`tsconfig.json`**, **`tsconfig.node.json`**, **`tsconfig.app.json`**: These are TypeScript configuration files. 
    - `tsconfig.json` is the base configuration.
    - `tsconfig.node.json` is specifically for the Node.js environment (e.g., for Vite's configuration file itself).
    - `tsconfig.app.json` contains configuration specifically for the application code in the `src` directory.

- **`eslint.config.js`**: This file configures ESLint, a tool that analyzes our code to find and fix problems, ensuring code quality and consistency.

- **`index.html`**: This is the main HTML page that is served to the browser. The React application is mounted into a `<div>` element inside this file.

### `public/` Directory

- **Purpose**: This directory contains static assets that are copied directly to the build output without being processed by Vite.
- **`vite.svg`**: The default Vite logo, which can be replaced or removed.

### `src/` Directory

- **Purpose**: This is where the main source code of our React application lives.

- **`main.tsx`**: The entry point of the application. It finds the root `div` in `index.html` and renders the `<App />` component into it.

- **`App.tsx`**: The main, top-level React component. It serves as the root of the component tree.

- **`index.css`**: The global CSS file. We have configured it to import the necessary Tailwind CSS layers (`@import "tailwindcss";`).

- **`vite-env.d.ts`**: A TypeScript declaration file that provides type definitions for Vite-specific environment variables (like `import.meta.env`).

- **`src/assets/`**: A directory within `src` for assets that might be imported and processed by Vite, such as images or fonts.
    - **`react.svg`**: The default React logo.
